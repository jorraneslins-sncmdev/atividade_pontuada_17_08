# Livraria Universal
Sistema web simples e eficiente para gerenciamento, cadastro e consulta do acervo de uma biblioteca.

## Sobre o Projeto.

O Projeto Livraria Universal é uma plataforma web desenvolvida para otimizar o fluxo de cadastro e consulta de livros em uma biblioteca. O sistema oferece uma interface intuitiva para a gestão do acervo, permitindo o registro detalhado de obras e o acesso fácil às informações cadastradas.

## Páginas do Sistema.

Login: Autenticação e acesso ao sistema.

Página Inicial (index.html): Apresentação e navegação principal.

Painel do Administrador: Área restrita para gestão e controle do sistema.

Cadastro de Livros: Formulário para inclusão de novos títulos no acervo.

Confirmação de Cadastro: Tela de validação do registro do livro.

Consulta de Livros: Interface de busca e listagem das obras cadastradas.


## Funcionalidades.

Cadastro de Livros:

Código ISBN

Título do Livro

Nome do Autor

Ano de Publicação


## Consulta e Listagem:

Visualização dos livros presentes no acervo.

Busca e filtro de obras cadastradas.

Controle de Acesso:

Autenticação de usuário e painel administrativo.


### Tecnologias Utilizadas
HTML5: Estruturação das páginas.

CSS3: Estilização e layout responsivo.

JavaScript: Lógica de navegação, validação de formulários e manipulação de dados.

VS Code: Ambiente de desenvolvimento (IDE).
